# Checkpoint IX - Cálculo de IMC Server-Side

Aplicação desenvolvida em ASP.NET Core MVC para a disciplina de Desenvolvimento Web (UNINOVE).

### O que foi programado:
- **Model Binding & Validação:** Criação da classe `Imc.cs` com atributos de validação (`DataAnnotations`) garantindo que peso e altura sejam informados e válidos.
- **Regra de Negócio (Server-Side):** O processamento e cálculo do IMC foram implementados diretamente no `ImcController.cs`, determinando a categoria (Abaixo do peso, Normal, Sobrepeso ou Obesidade).
- **Interface Responsiva:** View desenvolvida com Razor e estilizada utilizando classes do Bootstrap.
